Data Cleaning

This folder contains projects and practical examples demonstrating data cleaning and preparation techniques used in data analytics.

The work will cover:

Data quality assessment

Identification and treatment of missing values

Identification and removal of duplicate records

Data validation and consistency checks

Data transformation and standardisation

Preparation of datasets for analysis and visualisation

Projects will use practical datasets and demonstrate relevant techniques using Python, SQL and Excel.

Each project will include documentation explaining the data, cleaning methods, decisions made and final outputs.
